根目录通过 `package.json` 的 scripts 将三类子模块串联：`frontend_app`（React+Zustand 画布）由 Vite 构建为两套产物——`build:online` 输出到 `dist/` 走 Supabase/OSS 云同步，`build:lan` 输出到 `dist-lan/` 走本地 WebSocket 协作；`build_scripts` 在 `predev`/`predev:lan` 阶段拷贝 pdf.js 资源，并在 `scripts/build.mjs` 中根据 `.env.online` / `.env.lan` 的 `VITE_BUILD_TARGET` 切换构建目标，`scripts/package-lan.mjs` 进一步把 `server/` 与 Node 运行时打包成 release ZIP；`promo_assets` 作为独立 Node 流水线复用同一仓库的演示项目来录制宣传片。`vite.config.ts` 通过 `/lan-ws` 代理将开发期浏览器请求转发至 `server/lan-server.mjs` 提供的 8790 端口，使前端与局域网中继在同一进程内联调。环境配置由 `.env.example`、`.env.lan`、`.env.online` 三套文件区分，Windows 用户可通过 `start-lan.bat` 与 `npm run lan:open` 一键启动并放行防火墙。
