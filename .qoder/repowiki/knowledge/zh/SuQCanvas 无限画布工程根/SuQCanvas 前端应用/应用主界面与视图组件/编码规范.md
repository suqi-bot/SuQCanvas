- 组件通过 `useXxxStore((s) => s.field)` 订阅式读取 Zustand store 字段，并通过返回的 setter 方法触发状态变更，避免整棵 store 重渲染。
- 异步副作用统一使用 `let alive = true; ... if (!alive) return;` 守卫配合 useEffect 清理函数，防止组件卸载后更新 state 导致内存泄漏。
- 用户反馈统一通过 `toast(message, 'success'|'error')` 从 `../store/uiStore` 弹出，而非本地 alert 或 console。
- 大型或重型模块（如 `../media/pdf`、`AudioPlayerView`、`VideoPlayerView`）采用 `await import(...)` 动态按需加载，减少首屏体积。
- 模态/弹窗组件以 `viewer` 对象形式挂在 `uiStore` 上，组件内部判断 `if (!viewer) return null` 实现条件渲染，关闭时调用对应的 `closeXxxViewer`。
- UI 文案与样式统一使用 Tailwind 原子类，颜色/尺寸等常量集中定义为局部常量（如 `STATUS_LABEL`、`INSERT_ITEMS`、`ALIGN_BUTTONS`），再通过 map 渲染按钮组。
