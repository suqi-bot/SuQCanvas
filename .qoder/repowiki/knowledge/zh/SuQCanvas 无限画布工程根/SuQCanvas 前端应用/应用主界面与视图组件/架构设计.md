本模块由一组独立的 React 函数式组件构成，按职责划分为四类：
- 入口页面：`AuthPage`（登录/注册/游客模式，按 `IS_LAN_BUILD` 分支渲染局域网连接表单）、`HomePage`（项目列表、缩略图 Canvas 预览、导入导出、云/局域网项目合并展示）、`PlayerPage`（根据 `uiStore.playerPage.kind` 路由到音频或视频播放器全屏页）。
- 画布辅助 UI：`Toolbar`（顶部工具条，通过 `window.dispatchEvent('sq:add-node'/'sq:view')` 自定义事件向画布注入节点与视图操作，并集成插入菜单、撤销重做、对齐分布、缩放、主题切换、`LanPanel`）、`InspectorPanel`（右下角属性面板，基于 `useReactFlow` 删除元素，按选中节点/连线类型动态渲染段落，支持文字样式、层级、专辑图等编辑）。
- 协作面板：`LanPanel` 作为悬浮下拉面板，封装 `lanConnect/lanDisconnect` 连接流程、协作者列表、跟随与活动日志。
- 模态查看器：`FileManagerModal`（资源库，按媒体/文档/其他分组，支持搜索、多选下载/删除、内嵌音频播放）、`ImageViewerModal`（图片缩放/适应窗口/PSD 预览）、`MarkdownViewerModal`（加载 Markdown 文本、编辑后调用 `updateAssetText` 并通过 `setLanEditing/clearLanEditing` 协作锁定）、`PdfViewerModal`（懒加载 `../media/pdf`，用 Canvas 渲染 PDF 页）。
- 全局通知：`Toasts` 仅负责消费 `uiStore.toasts` 渲染底部居中提示。

依赖方向单向向下：所有组件通过 Zustand store（`authStore`、`projectStore`、`canvasStore`、`uiStore`、`settingsStore`、`playerStore`、`lanStore`）读写状态，通过 `../db/db` 访问 IndexedDB，通过 `../sync/*` 调用云/局域网同步 API，通过 `../media/*` 获取资源 URL；组件之间不直接互相 import，而是通过 store 和 DOM 事件解耦。构建期常量 `IS_LAN_BUILD`、`IS_ONLINE_BUILD` 用于在编译时裁剪不同部署形态的 UI。
