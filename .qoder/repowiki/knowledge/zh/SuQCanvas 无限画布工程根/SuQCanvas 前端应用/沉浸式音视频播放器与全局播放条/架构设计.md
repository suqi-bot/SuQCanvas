本模块由四个 React 组件构成清晰的职责分层：
- `GlobalPlayer`（src/components/GlobalPlayer.tsx）是应用级单例入口，挂载唯一的 `<audio>` 元素并通过 `bindPlayerAudio` / `registerAudio` 接入 `playerStore` 与 `mediaCoordinator`，同时暴露右上角可拖拽的迷你控制栏和桌面端画中画能力。
- `AudioPlayerView`（src/components/AudioPlayer.tsx）是音乐全屏播放器，通过 `usePlayerStore` 订阅播放状态，从 `canvasStore` 解析画布连线构建歌单顺序（`linearizeFrom`），并组合 `SpectrumBars` 与 `AudioBackground` 实现歌词滚动、专辑图轮换、封面取色与对比度自适应歌词配色。
- `VideoPlayerView`（src/components/VideoPlayer.tsx）是视频全屏播放器，直接操作原生 `<video>` 元素，通过 `mediaCoordinator.registerVideo` 与其他视频互斥播放，支持全屏、画中画、倍速、进度拖拽与右侧列表。
- `SpectrumBars`（src/components/SpectrumBars.tsx）与 `AudioBackground`（src/components/AudioBackground.tsx）为纯视觉子组件，分别用 Canvas + Web Audio AnalyserNode 绘制频谱条，以及用 Canvas 做封面 cover-fit 铺满与淡入过渡。
依赖方向单向向下：组件 → `store/playerStore`、`store/canvasStore`、`store/uiStore`、`media/*`（blobRegistry、playlists、lyrics、audioAnalyzer、pipWindow、mediaCoordinator）、`db/db`；组件之间仅通过 props 组合，无横向耦合。
