- 播放状态统一通过 Zustand store（`usePlayerStore`）读写，组件内不维护本地播放时间等状态，仅用 `useState` 管理 UI 开关（如队列面板、全屏、速率菜单）。
- 所有用户偏好（歌词偏移、收藏、歌词文字模式）通过 `localStorage` 的键值对持久化，并提供 `loadXxx` / `saveXxx` 封装函数并以 try/catch 兜底。
- 键盘快捷键在组件内部使用 `window.addEventListener('keydown')` 监听，并在卸载时移除，同时跳过 INPUT/TEXTAREA/SELECT 等输入态目标。
- Canvas 动画统一采用 `requestAnimationFrame` + `ResizeObserver` 响应尺寸变化，并在清理回调中 `cancelAnimationFrame` 与 `observer.disconnect`。
- 媒体资源 URL 统一经 `getAssetUrl` / `getThumbnailUrl` 从 `blobRegistry` 获取，下载功能通过动态创建 `<a>` 标签触发浏览器下载。
- 多张封面/图片场景使用 ref 保存上一帧对象（如 `transitionRef`、`currentNodesRef`），避免 React 重渲染导致的状态丢失或重复加载。
