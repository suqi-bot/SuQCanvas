模块以 `promo/` 为根，分为两条并行管线：
- 动画演示管线：`promo.html` 是单文件 HTML/CSS/JS 宣传片（9 个 scene 通过 CSS class 切换），由根级 `capture.mjs` 用 Playwright Chromium 打开该页面并录制为 MP4（依赖 ffmpeg 编码）。
- 真实应用录制管线：`record/` 目录实现完整流水线——`serve-dist.mjs` 启动静态服务器提供已构建的 SuQCanvas 在线版；`record.mjs` 作为主脚本加载应用、注入 `promo-bridge.js`（在页面中暴露 `__promo.cam/title/blank/progress` API 用于运镜、字幕卡、黑场过渡），按时间轴驱动真实操作并逐帧 `page.screenshot` 捕获 JPEG 到 `frames_cap/`，最后调用 ffmpeg 合成 mp4 并混入 `bgm.wav`；`run.mjs` 串联构建、生成 demo、服务、录制、停止的全流程。
- 演示项目生成：`apple/build-demo.mjs` 使用 `fflate` 将 `apple/work/photos/` 中的照片、Markdown、PDF、音频、视频等素材打包成 `.sqcanvas` 项目文件，供录制管线导入；`fetch-photos.mjs` 从 picsum 下载素材。
依赖方向单向：`record/*` → 真实应用 → `apple/demo.sqcanvas` → `apple/work/*` 素材；`capture.mjs` 独立于真实应用，仅依赖 `promo.html`。
