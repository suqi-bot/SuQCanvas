- 录制脚本通过 `page.addInitScript` 注入桥接代码（`localStorage.sq:guest=1` 游客模式 + `window.__promo.*` API），将控制逻辑与页面内容解耦。
- ffmpeg 可执行文件通过 `findFfmpeg()` 函数按固定优先级查找：系统 PATH → WinGet 包目录 → ms-playwright 内置目录，找不到则报错退出。
- 宣传片场景统一使用 CSS class 切换：`.scene` 默认隐藏，`.scene.active` 显示，配合 `.anim` / `.d1..d12` 延迟类实现入场动画。
- 演示项目节点与连线通过工厂函数（`P(x,y)`、`E(id,source,target,...)`）集中声明，再批量写入 JSON 并 zip 为 .sqcanvas。
- 录制剧本以顺序 `await sleep(D(sec))` 编排镜头，每个镜头组合运镜（focusNode/glideTo/fitView）、真实操作（点击/双击/键盘事件）和字幕卡（title/clearTitle/blank/clearBlank）。
