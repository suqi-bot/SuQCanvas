- 构建目标通过 `.env.*` 中的 `VITE_BUILD_TARGET` 环境变量在在线版与局域网版之间切换，而非多份源码分支。
- 所有脚本统一放在 `scripts/` 目录下并以 ES Module（`.mjs`）形式编写，由 `package.json` scripts 调用。
- 开发服务器通过 Vite 的 `/lan-ws` 代理将 WebSocket 请求转发到本机 8790 端口的局域网中继，前后端联调无需额外配置。
- 生产部署时在线版与局域网版产物分离（`dist/` 与 `dist-lan/`），并通过 `release/` ZIP 包附带 `server/` 与 Node 运行时供 Windows 一键启动。
