脚本按职责拆分为四个独立入口，均通过 `node:child_process` 或 `fs/promises` 调用外部工具，不依赖项目运行时：
- `build.mjs`：顶层编排脚本，解析命令行参数（online/lan/all）并通过交互式 readline 选择目标，依次调用 `copy-pdfjs-assets.mjs` 复制 PDF.js 的 cmaps/standard_fonts/wasm 到 `public/pdfjs`，检测 `.env*` 中 Supabase 环境变量并发出警告，再使用 `spawnSync` 直接执行 `node_modules/vite/bin/vite.js build --mode <target>` 输出到 `dist` 或 `dist-lan`。
- `package-lan.mjs`：将已构建的 `dist-lan`、`server/lan-server.mjs`、`ws` 依赖、内置 `runtime/node.exe`、启动脚本及说明文档复制到 `release/SuQCanvas-LAN/`，生成最小化 `package.json` 和 `README.txt`，优先用 `tar.exe -a` 压缩为 ZIP，回退到 PowerShell `Compress-Archive`。
- `start-lan.ps1`：运行期启动器，优先使用打包内嵌的 `runtime/node.exe`，否则回退系统 `node`；自动检测并调用 `open-lan-firewall.ps1` 放行 TCP 8790；枚举本机 IPv4 地址打印 LAN URL，设置 `NODE_OPTIONS=max-old-space-size=8192` 后启动 `server/lan-server.mjs`。
- `open-lan-firewall.ps1`：以管理员权限提升方式创建/启用 Windows 防火墙规则，允许本地子网访问 TCP 8790（生产）与 5174（开发）端口。
依赖方向单向：`build.mjs` → `copy-pdfjs-assets.mjs`；`package-lan.mjs` 仅消费构建产物；两个 PowerShell 脚本相互独立但被 `start-lan.ps1` 在运行时按需调用。
