- 所有 Node 脚本通过 `resolve(dirname(fileURLToPath(import.meta.url)), '..')` 计算仓库根目录，再以相对路径引用其他脚本与资源，避免硬编码绝对路径。
- 对外部命令（vite、tar、powershell）统一使用 `spawnSync(process.execPath, ..., { cwd: root, stdio: 'inherit' })` 并以 `status !== 0` 时 `process.exit` 快速失败。
- PowerShell 脚本顶部设置 `$ErrorActionPreference = 'Stop'`，并在需要管理员权限时通过 `Start-Process powershell.exe -Verb RunAs` 自我提权。
- 构建产物输出目录与模式一一对应：online → `--mode online --outDir dist`，lan → `--mode lan --outDir dist-lan`，由 TARGETS 映射集中管理。
- 环境配置读取遵循优先级链 `.env` → `.env.local` → `.env.online` → `.env.online.local` → `process.env`，匹配 `^[A-Z0-9_]+\s*=\s*(.*)$` 格式并去除引号。
