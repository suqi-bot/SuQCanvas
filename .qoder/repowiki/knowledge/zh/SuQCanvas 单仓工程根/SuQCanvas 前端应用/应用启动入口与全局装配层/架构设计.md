本模块是前端工程的最外层边界，按文件职责清晰分层：`main.tsx` 通过 `react-dom/client` 的 `createRoot` 将 `<App />` 挂载到 `#root` 节点并引入全局样式；`App.tsx` 作为根组件编排生命周期——首次渲染时调用 `useAuthStore.getState().init()` 初始化认证状态，依据 `IS_LAN_BUILD` 分支决定是否执行 `autoReconnectLan`/`repairStuckUploads` 与 `initLanSync`，用户进入后触发 `useUiStore` 与 `useProjectStore` 的初始化，并按登录态路由到 `AuthPage` 或主界面（`Toolbar` + `CanvasBoard` + 各类 Modal/页面/`Toasts`/`GlobalPlayer`）；`types.ts` 集中定义画布领域模型（`MediaKind`、`SuqNodeData`、`SuqEdgeData`、`SuqNode`、`SuqEdge` 等），为下游 canvas、store、components 共享；`buildMode.ts` 通过 `import.meta.env.VITE_BUILD_TARGET` 导出 `IS_LAN_BUILD` / `IS_ONLINE_BUILD` 布尔常量，配合 Vite 打包实现 lan/online 双目标死代码消除；`appVersion.ts` 提供单一版本字符串出口 `APP_VERSION`；`index.css` 使用 Tailwind CSS v4 的 `@theme inline` 声明主题变量，并通过 `:root` / `html.light` 两套 CSS 变量实现暗色/亮色主题切换，同时覆盖 react-flow 控件样式与播放器、Markdown、Toast 等全局 UI 样式。依赖方向单向向下：入口 → 组件/Store/Sync，不反向引用业务子模块。
