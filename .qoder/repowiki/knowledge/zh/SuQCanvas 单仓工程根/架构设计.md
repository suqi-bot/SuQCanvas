根目录作为单仓装配中心，通过 `package.json` scripts 串联三个子模块：`frontend_app` 由 Vite 根据 `.env.*` 中的 `VITE_BUILD_TARGET` 分别产出到 `dist/`（走 Supabase/OSS 云同步）与 `dist-lan/`（走本地 WebSocket 协作）；`build_scripts` 在 `predev`/`predev:lan` 阶段拷贝 pdf.js 资源，并在 `scripts/build.mjs`、`scripts/package-lan.mjs` 中按目标切换构建与打包逻辑，最终生成含 Node 运行时的 release ZIP；`promo_assets` 复用同一仓库的演示项目生成 Apple 风格宣传片。开发期 `vite.config.ts` 通过 `/lan-ws` 代理将浏览器请求转发至本机 8790 端口的局域网中继，使前后端联调无需额外配置。环境配置由 `.env.example`、`.env.lan`、`.env.online` 三套文件区分，Windows 用户可通过 `start-lan.bat` 与 `npm run lan:open` 一键启动并放行防火墙。
