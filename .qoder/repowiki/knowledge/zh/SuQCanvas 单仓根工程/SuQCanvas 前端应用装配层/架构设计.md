src/main.tsx 仅负责 DOM 挂载与全局样式注入，真正的装配在 src/App.tsx：启动时调用 useAuthStore.init() 完成鉴权，再根据 buildMode.ts 的 IS_LAN_BUILD 决定初始化 sync/ 中的局域网协作（initLanSync/autoReconnectLan）还是执行 repairStuckUploads；鉴权完成后统一渲染 Toolbar + CanvasBoard + HomePage + 各类 Modal + GlobalPlayer + Toasts，形成「工具栏-画布-底部面板」的固定布局。
跨子模块通过共享状态解耦：canvas/ 节点消费 media/ 下的 mediaCoordinator 与 blobRegistry 管理媒体资源，components/ 页面通过 store/ 下的 Zustand store（authStore、projectStore、canvasStore、playerStore、uiStore、uploadStore、lanStore、settingsStore）订阅播放与 UI 状态，sync/ 由入口统一初始化后供上层隐式使用；db/ 提供本地持久化，io/ 负责导入导出，search/ 提供模糊搜索，utils/ 提供设备 ID 与 UUID。构建期常量 IS_LAN_BUILD 决定最终产物是否启用局域网协作能力。
