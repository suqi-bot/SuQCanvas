本模块是前端应用的启动层，职责清晰分层：`main.tsx` 通过 `react-dom/client` 的 `createRoot` 挂载到 DOM 的 `#root` 节点并渲染 `App`；`index.css` 注入全局 Tailwind CSS 变量与基础样式；`App.tsx` 作为根组件负责生命周期编排——初始化认证状态（`useAuthStore.init`）、在局域网构建下启动 LAN 同步（`initLanSync` / `autoReconnectLan`），并根据登录态路由到 `AuthPage` 或主界面（`Toolbar` + `CanvasBoard` + 各类 Modal/页面/`Toasts`）；`types.ts` 集中定义画布领域模型（`MediaKind`、`SuqNodeData`、`SuqEdgeData`、`SuqNode`、`SuqEdge` 等），为下游 canvas、store、components 共享；`buildMode.ts` 通过 `import.meta.env.VITE_BUILD_TARGET` 暴露构建期布尔常量，配合 Vite 环境变量实现 lan/online 双构建目标下的死代码消除；`appVersion.ts` 提供单一版本字符串出口。依赖方向单向向下：入口 → 组件/Store/Sync，不反向引用业务子模块。
