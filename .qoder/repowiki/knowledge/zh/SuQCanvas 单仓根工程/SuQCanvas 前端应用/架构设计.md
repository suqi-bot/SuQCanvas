src/main.tsx 通过 createRoot 挂载 App；App 在启动时调用 useAuthStore.init() 完成鉴权，并根据 buildMode.ts 中的 IS_LAN_BUILD 决定是否初始化局域网同步（initLanSync/autoReconnectLan）。App 作为唯一编排点，自上而下渲染 Toolbar → CanvasBoard → HomePage → 各 ViewerModal → GlobalPlayer → Toasts，所有子模块之间不直接耦合，仅通过 store/ 下的 Zustand store（authStore、projectStore、canvasStore、playerStore、uiStore）共享状态，并通过 media/ 与 sync/ 暴露的服务进行通信：canvas/ 节点消费 mediaCoordinator 与 blobRegistry 管理媒体资源，components/ 页面通过 store 订阅播放与 UI 状态，sync/ 由入口统一初始化后供上层隐式使用。构建期常量 IS_LAN_BUILD 决定最终产物是否启用局域网协作能力。
