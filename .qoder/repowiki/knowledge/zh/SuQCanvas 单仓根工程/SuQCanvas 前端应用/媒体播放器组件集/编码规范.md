- 播放状态统一通过 Zustand store（`usePlayerStore`）读写，组件内仅用 `useState` 管理 UI 开关。
- 用户偏好（歌词偏移、收藏、歌词文字模式）经 `loadXxx` / `saveXxx` 封装的 localStorage 持久化并以 try/catch 兜底。
- 键盘快捷键在组件内部使用 `window.addEventListener('keydown')` 监听并在卸载时移除，同时跳过输入态目标。
- Canvas 动画统一采用 `requestAnimationFrame` + `ResizeObserver`，清理回调中取消帧与断开观察器。
- 媒体资源 URL 统一经 `getAssetUrl` / `getThumbnailUrl` 从 `blobRegistry` 获取，下载通过动态 `<a>` 标签触发。
- 多帧/多图场景使用 ref 保存上一帧对象，避免 React 重渲染导致的状态丢失或重复加载。
