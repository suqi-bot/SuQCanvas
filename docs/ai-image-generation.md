# AI 生图

画布工具栏 → **AI 生图设置**，然后通过「插入 → AI 图片」创建生成节点。

## 本地 ComfyUI

1. 地址填写 `http://127.0.0.1:8188`，本地无鉴权时 Key 留空。
2. 点击「测试连接」，再点击「读取最近成功工作流」。也可导入 ComfyUI 导出的 **API 格式** JSON，普通画布 JSON 不适用。
3. 核对提示词输入节点。Qwen Image 2.1 通常选 `TextEncodeQwenImage21` 的 `prompt`；SD 工作流选择正向 `CLIPTextEncode` 的 `text`。
4. 可单独绑定反向提示词输入（例如负向 `CLIPTextEncode.text` 或 `negative_prompt`），不能与正向词绑定同一输入。未绑定时保留工作流原值；已绑定时可以输入空文本清除原有负面词。复杂多文本编码工作流请在 ComfyUI 先统一输入。
5. 点击画布中的 AI 图片，在浮层输入画面描述和反向提示词并发送。生成在后台执行，结果写入原节点，多张输出作为独立图片加入画布；可在「AI 任务」查看结果。提示词及参数随图片保存。
6. 也可右键插入独立「提示词」节点（含正向、反向与「优化提示词」）。用连线把提示词节点接到 AI 图片后，会自动填充该图的草稿提示词；此时点击 AI 图片只能查看、不能修改提示词，请在提示词节点中编辑。删除连线后恢复可编辑。

「保存配置」将地址、模型、工作流保存在当前设备浏览器存储，不随项目同步。API Key 单独保存在本机凭据中（网页版 localStorage 键 `suqcanvas-ai-credentials-v1`；桌面版 `userData/ai-credentials.json`），输入后即时写入，重启/刷新会自动恢复，不随项目导出。工作流 JSON 本身若含自定义节点凭据，保存前应在 ComfyUI 清除这些凭据。

调用流程：`GET /system_stats` 检查服务，`GET /history?max_items=20` 获取最近成功的工作流，`POST /prompt` 提交 API 工作流，轮询 `GET /history/{prompt_id}`，最后通过 `GET /view` 下载图片。等待上限 30 分钟，单个 HTTP 请求上限 3 分钟。停止等待不会中断服务端任务，可回到 ComfyUI 查看结果。

桌面版通过主进程直接连接 HTTP(S) 服务。Vite 开发版对 `http://127.0.0.1:8188` 提供固定本地代理。正式网页版及其他服务地址使用浏览器直连，服务需配置允许页面源的 CORS；HTTPS 页面应使用 HTTPS 服务或桌面版。`127.0.0.1` 始终表示运行画布的设备，不是局域网服务器。

## 云端 / 本地 OpenAI 兼容接口

选择「OpenAI 兼容 Images API」，填写 Base URL（通常含 `/v1`）、Key、模型名及服务商支持的尺寸。客户端调用 `POST {Base URL}/images/generations`，传入 `model/prompt/n:1/size`，支持 `data[].b64_json` 或 `data[].url`。仅兼容 Chat API 的服务不能用于生图；异步任务式或其他专有协议暂不支持。下载返回的图片 URL 时不会携带 API Key。

填写反向提示词时额外发送 `negative_prompt` 扩展字段，这不是所有 Images API 都支持的参数。不支持此扩展的服务请留空；客户端不会默默丢弃反向词或将其混入正向词。

## 图生图

鼠标移到普通图片或 AI 图片，点击右上角「图生图」。两种模式都保留原图，结果放在旁边，可关闭面板继续编辑，在「AI 任务」查看进度及下载结果。

- **网格裁切**：配置行数、列数、像素间距和外边距，预览裁切区域后开始。裁切在本机执行，最多 100 张，输出 PNG 并保留原有透明度。原图像素不能超过 6400 万。任务中断后可从任务列表恢复本地裁切。
- **图生图 / AI 分层**：在「AI 生图设置 → 图生图调用方式」选择调用方式。
  - **OpenAI 兼容（图生图）**：填写 Base URL、API Key、模型名与输出张数（1–4）。客户端调用 `POST {Base URL}/images/edits`，multipart 上传原图与 prompt，返回的每张图作为独立图片写入画布。需服务支持 Images edits 接口。
  - **ComfyUI 工作流（分层）**：导入已跑通的 ComfyUI API 工作流，绑定 `LoadImage.image` 等原图输入，可选绑定正向和反向提示词。需要服务端安装分层/分割模型；原图最多 32MB，经 `/upload/image` 上传后提交工作流；每张输出作为独立图片保存。

已取得服务端任务编号的 ComfyUI 分层任务可恢复等待，不会重复提交。在线项目结果先保存在本机，重新打开原项目后写入。图生图配置独立保存，不覆盖日常生图工作流（ComfyUI 分层仍与生图共用 ComfyUI 地址）。

图生图（OpenAI 兼容）调用链：

1. 「AI 生图设置 → 图生图调用方式」选「OpenAI 兼容」，填 Base URL、Key、模型与输出张数。
2. 图片节点 →「图生图」，填写图生图需求后开始。
3. `POST {Base URL}/images/edits`（multipart：`image` + `prompt` + `model` + `n`）。
4. 解析 `data[].b64_json` 或 `data[].url`，每张输出作为独立图片加入画布。

ComfyUI 分层调用链（与生图共用 ComfyUI API Key）：

1. 导入 API 格式 JSON，绑定原图输入及可选正/反提示词。
2. 图片节点 →「图生图」→「AI 分层」，校验工作流绑定后创建后台任务。
3. `POST /upload/image` 上传原图（≤32MB），把返回文件名写入工作流图片输入。
4. `POST /prompt` 提交已填入提示词的工作流，记录 `prompt_id`。
5. 轮询 `GET /history/{prompt_id}`，完成后 `GET /view` 下载每张输出图并写入画布。

网页版需服务允许 CORS；桌面版由主进程直连。Key 从本机凭据读取。

## 文生图 / 图生图

画布中 AI 图片的提示词浮层，以及「提示词」节点，均可选择**生成方式**：

- **文生图**：默认行为，按提示词生成新图。
- **图生图（编辑当前图片）**：接管本次生成，把该节点已有的图片作为原图发送到「AI 生图设置 → 图生图调用方式」配置的服务（OpenAI 兼容 `/images/edits` 或千问 `multimodal-generation`）。节点还没有图片、或未配置图生图服务地址时无法发送。提示词节点上的选择会随连线同步到已连接的 AI 图片。

图生图完成后**不直接替换**原图：图片上出现对比线，左右拖动查看改前 / 改后；顶部点「应用」才把节点替换为新图，点「放弃」保留原图。结果在应用前已持久化，刷新或重开项目后仍可对比。

## 提示词优化

不是生图的必需步骤。Qwen Image 等支持自然语言的模型可先直接输入中文。需要补足构图、光线、材质时，可在 AI 图片浮层或独立「提示词」节点上使用「✧ 优化提示词」；也可展开「AI 提示词优化」，单独填写文字模型地址、Key 和模型名。调用兼容的 `/chat/completions`，同时提交当前正向与负面提示词，要求保留已有意图和限制，并分别预览两部分优化结果。点击「同时采用」才写入对应草稿；「保留原文」不修改内容，也不会自动触发生图。模型返回格式不正确或缺少任一字段时显示错误并保留原文。可连接支持该协议的本地文字模型服务，也可连接云端服务。

API 参考：[ComfyUI 官方路由文档](https://docs.comfy.org/development/comfyui-server/comms_routes)。
