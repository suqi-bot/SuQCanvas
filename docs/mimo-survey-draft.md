## 版本一：标准版（约 320 字，推荐）

我用 AI 从零做了一个浏览器端无限画布应用 SuQCanvas（React 19 + TypeScript + React Flow，约 1.9 万行代码、99 个源文件）。它可以把图片、视频、音频、PDF、Markdown、PSD 等各类文件直接拖进同一张画布，节点间自由连线组织关系，数据自动存入 IndexedDB，并支持导出 .sqcanvas 工程文件迁移到任何浏览器还原。开发中遇到并解决了一批真实工程问题：大视频在画布上卡顿（做了视口外自动卸载 + 自动抽帧封面）、IndexedDB Blob 与 zip 打包导入导出的数据一致性（用 vitest 写了往返一致性测试）、HTTPS 页面禁止连接 ws://（用 Nginx 把中继反代成 wss://）。应用发布了两个版本：Supabase + 阿里云 OSS 的云端账号版，和免登录、WebSocket 实时多人协作、可打包成 Windows 一键启动包的局域网版，已在真实局域网环境部署使用。全程由 AI 编程智能体完成代码生成、调试、测试、打包和部署脚本，我负责提需求、验收和架构把关。附项目演示视频和截图。

## 版本二：详细版（约 520 字，信息量更大）

**做了什么**：我用 AI 从零开发并维护了一个名为 SuQCanvas 的浏览器端无限画布应用，技术栈 React 19 + TypeScript + Vite + React Flow v12 + Zustand + Dexie(IndexedDB) + Tailwind v4，共约 1.9 万行代码。功能上支持把图片、视频（自动抽帧封面、视口外自动卸载）、音频（内置播放器）、PDF（pdfjs 分包懒加载 + 多页翻页）、Markdown（即时渲染）、PSD（ag-psd 解析）等拖到同一张无限画布上，节点四边锚点拖拽连线，支持实线/虚线/点线、曲线/直线/阶梯等多种线型箭头组合，右侧面板批量编辑样式；数据 500ms 自动保存到 IndexedDB，可一键导出 .sqcanvas（zip 打包画布 + 原始媒体）跨浏览器迁移。产品分为两个发行版：在线版（Supabase 账号登录 + 云同步 + 阿里云 OSS 媒体存储）和局域网版（免登录，WebSocket 中继按房间实时协作，主副本持久化在主机，带项目所有权、误删 24 小时备份恢复、素材垃圾回收，还能打包成内置 Node 运行时的 Windows 一键启动包）。

**遇到的问题**：① 大视频拖入画布后内存暴涨卡顿 → 做了视口外自动卸载 Blob URL 和抽帧封面；② IndexedDB Blob 存储与 zip 导入导出的往返一致性 → 用 vitest 覆盖往返测试；③ HTTPS 页面浏览器禁止 ws:// → Nginx 反代为 wss:// 并处理素材流式拉流的跨域头；④ 多人协作的项目冲突与误删 → 设计设备 ID 所有权 + 服务端 24 小时备份窗口。

**用了哪些工具**：全程使用 AI 编程智能体（对话式开发）完成代码生成、Bug 定位、测试编写、构建打包脚本（在线/局域网双 target）、部署文档（含 Nginx 配置示例）与宣传视频制作，我负责提需求、验收效果和架构决策。相信这些经验可以完整迁移到 MiMo Desktop 上。
