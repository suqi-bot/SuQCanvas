# SuQCanvas 桌面版 1.4.5

## 更新内容

- 网易云音乐可从歌单和搜索结果播放，并将歌曲插入画布节点；修复歌曲起播后状态不同步、重复起播和报错问题。
- 网易云歌曲接入现有悬浮播放器和音乐播放器，支持暂停、上一首、下一首及拖动进度条跳转。关闭网易云侧栏后继续播放。
- 保留画布音乐节点的连线顺序播放；播放到连线末尾时停止，不再继续播放其它歌曲。
- 改进桌面端 AI 生图请求、提示词连线工作流和任务恢复。

## 下载与安装

下载 `SuQCanvas-Desktop-1.4.5-Setup-x64.exe` 并运行。已有桌面版可直接安装更新，原有本地项目保存在用户数据目录。
