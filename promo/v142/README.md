# SuQCanvas 1.4.2 横版宣传样片

定位：面向设计师与创作者，用「从灵感到画面，在一张画布完成」串起产品价值。适合 B 站、官网及产品发布页。当前成片是**真实界面截图 + 动态排版与运镜**的方向样片，不是连续操作录屏。

交付：`SuQCanvas-1.4.2-promo-1080p.mp4`，1920×1080，30 fps，50 秒，H.264 + AAC。中文画面文案与背景氛围音乐，无配音。

已检查七个分镜的代表帧，并抽取最终 MP4 的 AI 镜头复核。FFprobe 确认 1500 帧、50.000 秒、双声道 AAC；FFmpeg 全片解码无错误。原始配乐整体偏低，混音提高 28 dB，并加入片头片尾淡入淡出。

## 实现与边界

- 应用来源：当前工作区 1.4.2，提交 `aa9eb07`。`npx vite build --mode desktop --outDir promo/v142/app --base /` 构建真实桌面版前端；在隔离浏览器上下文中加载，不读取个人项目或登录状态。
- 界面素材由 `capture-ui.mjs` 导入仓库已有 `promo/apple/demo.sqcanvas` 后采集；AI 节点经应用现有 `sq:add-node` 事件创建，使用真实输入框填写提示词。
- 没有连接模型、没有发起付费生成，视频不展示伪造的生成结果或生成耗时。画面明确说明生成服务需要配置。
- 本地自动保存与云端手动保存分开表述；没有声称自动双向云同步。
- 照片来自仓库既有 `promo/apple/work/photos/`，沿用原演示项目素材；配乐沿用 `promo/record/bgm.wav`。本次没有新增外部素材采购或生成。
- 未修改应用源代码、旧版宣传片或旧版录制脚本。

## 复现

从仓库根目录执行，使用既有 `promo/node_modules/playwright-core`、本机 Chromium 和 FFmpeg：

```powershell
npx vite build --mode desktop --outDir promo/v142/app --base /
node promo/v142/capture-ui.mjs
node promo/v142/render.mjs --preview
node promo/v142/render.mjs
```

`film.html` 保存排版、文案与时间轴；`window.seek(秒数)` 可定位任意时刻。`preview-1.jpg` 至 `preview-7.jpg` 是各段中间帧，供快速审阅。

## 下一版建议

当前样片适合确认风格和叙事。正式发布版最值得补的是一段真实 AI 生成成功的连续操作：输入一句话 → 后台生成时继续整理 → 结果回到画布。接入用户选定的可用模型后录制，按实际等待时间剪辑，不标注未经测量的速度。结束画面可换成确定的下载入口或二维码；目前没有编造发布网址。

建议发布标题：**SuQCanvas 1.4.2｜从灵感到画面，在一张画布完成**。

建议简介：把图片、视频、音频和文档放进无限画布，用笔记与连线整理思路。SuQCanvas 1.4.2 带来画布内 AI 图片创作入口，可连接 ComfyUI 或 OpenAI 兼容 Images API。桌面版本地保存，随时继续创作。
